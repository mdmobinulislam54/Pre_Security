# DNS — Quick Notes

**DNS (Domain Name System)** translates domain names into IP addresses, so we don't need to memorize IP addresses.

### 🔹 DNS Details

* **Layer:** Application Layer (Layer 7)
* **UDP:** Port **53**
* **TCP:** Port **53** (used when needed)

### 🔹 Common DNS Records

| Record    | Purpose                        | Example                         |
| --------- | ------------------------------ | ------------------------------- |
| **A**     | Maps hostname → IPv4 address   | `example.com → 93.184.215.14`   |
| **AAAA**  | Maps hostname → IPv6 address   | `example.com → 2606:...`        |
| **CNAME** | Maps a domain → another domain | `www.example.com → example.com` |
| **MX**    | Specifies the mail server      | `example.com → mail server`     |

### 🔍 DNS Lookup

Use `nslookup` to query DNS:

```bash
nslookup example.com
```

Example:

```text
Server:  127.0.0.53
Address: 127.0.0.53#53

Name:    www.example.com
Address: 93.184.215.14
```

### 🧠 Remember

* **A → IPv4**
* **AAAA → IPv6**
* **CNAME → Another domain name**
* **MX → Mail server**
* **DNS → Domain name → IP address**
* **DNS → Layer 7**
* **DNS → Port 53**

**DHCP** can automatically provide a device with its **IP address, gateway, and DNS server**.




# WHOIS — Quick Notes

**WHOIS** is a service used to look up registration information about a domain name.

### 🔹 What WHOIS Can Show

* Domain name
* **Creation date**
* Last updated date
* Expiration date
* Registrar
* Registrant information (if not protected by privacy services)
* Registrar contact information

### 🔍 Command

On Linux:

```bash
whois example.com
```

Look for fields such as:

```text
Creation Date:
Updated Date:
Registrar:
Registrant:
```

### 🔐 Privacy Protection

Domain owners can use **WHOIS privacy protection** to hide personal information such as their name, address, phone number, and email.

### 🧠 Remember

**WHOIS → Domain registration information**

**Creation Date → When the domain was registered**

**Registrar → Company managing the domain registration**




# HTTP — Quick Notes

**HTTP (Hypertext Transfer Protocol)** is an application-layer protocol used for communication between **web browsers and web servers**.

### 🔹 Common Ports

* **HTTP → TCP 80**
* **HTTPS → TCP 443**
* Other common ports: **8080, 8443**

### 🔹 HTTP Methods

| Method     | Purpose                               |
| ---------- | ------------------------------------- |
| **GET**    | Retrieve data/resource                |
| **POST**   | Submit or send new data               |
| **PUT**    | Create or update/overwrite a resource |
| **DELETE** | Delete a resource                     |

### 🔍 Using Telnet with HTTP

Telnet can be used to manually communicate with an HTTP server:

```bash
telnet MACHINE_IP 80
```

Request the main page:

```http
GET / HTTP/1.1
Host: anything
```

Request a specific file:

```http
GET /flag.html HTTP/1.1
Host: anything
```

Press **Enter twice** after the `Host` header.

### 📡 Basic HTTP Communication

```text
Browser ── HTTP Request ──> Web Server
Browser <─ HTTP Response ── Web Server
```

The response can contain:

* Status code
* Headers
* Server information
* Requested webpage/data

### 🧠 Remember

**HTTP → Layer 7 → TCP → Port 80**

**HTTPS → Secure HTTP → TCP → Port 443**

**GET → Retrieve**

**POST → Submit**

**PUT → Create/Update**

**DELETE → Remove**




# FTP — Quick Notes

**FTP (File Transfer Protocol)** is an application-layer protocol designed to **upload and download files** between a client and server.

### 🔹 FTP Details

* **Layer:** Application Layer (Layer 7)
* **Control connection:** TCP **21**
* Uses a **separate connection for data transfer**
* Commonly supports **anonymous login**

### 🔹 Common FTP Commands

| Command | Purpose                |
| ------- | ---------------------- |
| `USER`  | Enter username         |
| `PASS`  | Enter password         |
| `LIST`  | List files/directories |
| `RETR`  | Download a file        |
| `STOR`  | Upload a file          |
| `QUIT`  | Close the connection   |

### 🔍 FTP Example

Connect to a server:

```bash
ftp 10.49.140.154
```

Login:

```text
Name: anonymous
Password: [press Enter]
```

List available files:

```text
ftp> ls
```

Download the flag:

```text
ftp> get flag.txt
```

Exit:

```text
ftp> quit
```

Read the downloaded file:

```bash
cat flag.txt
```

### 🧠 Remember

**FTP → File Transfer → TCP Port 21**

**RETR → Download**

**STOR → Upload**

**`ls` → List files**

**`get flag.txt` → Download flag.txt**

> The exact flag is generated by the TryHackMe lab, so retrieve it with `cat flag.txt` rather than guessing it.




# SMTP — Quick Notes

**SMTP (Simple Mail Transfer Protocol)** is used to **send email** between mail clients and mail servers, and between mail servers.

### 🔹 SMTP Details

* **Layer:** Application Layer (Layer 7)
* **Default port:** TCP **25**

### 🔹 Common SMTP Commands

| Command         | Purpose                          |
| --------------- | -------------------------------- |
| `HELO` / `EHLO` | Start an SMTP session            |
| `MAIL FROM`     | Specify sender                   |
| `RCPT TO`       | Specify recipient                |
| `DATA`          | Start entering the email content |
| `.`             | End the email message            |
| `QUIT`          | Close the SMTP session           |

### 📧 Basic SMTP Flow

```text
HELO
MAIL FROM: <sender>
RCPT TO: <recipient>
DATA
Email content
.
QUIT
```

### 🧠 Remember

**DATA → Start email content**

**`.` → End email content**

**SMTP → Send email → TCP Port 25**




# POP3 — Quick Notes

**POP3 (Post Office Protocol version 3)** is used by email clients to **retrieve emails from a mail server**.

### 🔹 POP3 Details

* **Layer:** Application Layer (Layer 7)
* **Default port:** TCP **110**
* **Purpose:** Retrieve email messages
* **SMTP → Sends email**
* **POP3 → Retrieves email**

### 🔹 Common POP3 Commands

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `USER`  | Specify username                       |
| `PASS`  | Specify password                       |
| `STAT`  | Show number and total size of messages |
| `LIST`  | List messages and sizes                |
| `RETR`  | Retrieve a message                     |
| `DELE`  | Mark a message for deletion            |
| `QUIT`  | End the session                        |

### 🔍 Connect Using Telnet

```bash id="3qbl4k"
telnet 10.49.140.154 110
```

Login:

```text id="5b9c7j"
USER linda
PASS Pa$$123
```

List messages:

```text id="6e2j4m"
LIST
```

Retrieve the **4th message**:

```text id="m2td4w"
RETR 4
```

Look through the returned email for the `THM{...}` flag.

Exit:

```text id="h5x2kc"
QUIT
```

### 🖥️ POP3 Server

The banner in the example says:

```text
+OK [XCLIENT] Dovecot (Ubuntu) ready.
```

So the POP3 server is **Dovecot**.

### 🧠 Remember

**SMTP → Send**

**POP3 → Retrieve**

**POP3 → TCP 110**

**RETR → Retrieve a message**

**Dovecot → POP3 server in this lab**




# IMAP — Quick Notes

**IMAP (Internet Message Access Protocol)** allows email clients to **synchronize emails** while keeping messages stored on the mail server.

### 🔹 IMAP vs POP3

| Protocol | Purpose                                                         |
| -------- | --------------------------------------------------------------- |
| **POP3** | Downloads/retrieves emails, often removing them from the server |
| **IMAP** | Keeps emails on the server and synchronizes them across devices |

### 🔹 IMAP Details

* **Layer:** Application Layer (Layer 7)
* **Default port:** TCP **143**
* Supports synchronization of **read, moved, and deleted** messages.

### 🔹 Common IMAP Commands

| Command  | Purpose                 |
| -------- | ----------------------- |
| `LOGIN`  | Authenticate user       |
| `SELECT` | Select a mailbox/folder |
| `FETCH`  | Retrieve email data     |
| `MOVE`   | Move messages           |
| `COPY`   | Copy messages           |
| `LOGOUT` | End the session         |

### 📧 Retrieve an Email

First select the inbox:

```text id="m3c1q8"
B SELECT inbox
```

Then retrieve message 4:

```text id="k7x2pn"
C FETCH 4 body[]
```

### 🧠 Answer

**IMAP command to retrieve the fourth email:**

```text id="q6n4sv"
FETCH 4 body[]
```

**IMAP → TCP 143 → Email synchronization**
